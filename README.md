# Data Analysis & Feature Engineering 

A repository containing NumPy, Pandas, Data Preprocessing pipelines, Exploratory Data Analysis (EDA), and end-to-end data analytics projects.

##  Topics & Files Included

* **NumPy & Arrays:**
  * Fundamentals, Array Properties & Operations (`my_numpy.py`, `numpy_array_properties.py`, `numpy_work.py`)
  * Practice & Test Questions (`practice_question_numpy`, `Numpy test.txt`)

* **Pandas & Data Manipulation:**
  * File I/O & Core Functions (`import_export_pd.py`, `pandas_functions.txt`, `cleaned_flipkart_data.csv`)
  * Data Wrangling Practice (`practice_work_pandas.txt`, `python_pandas_work.txt`)

* **Feature Preprocessing & Pipelines:**
  * One-Hot Encoding & Column Transformers (`column transformer_practice.txt`, `complete practice_upto_onehot_en.txt`)

* **EDA & Analytics Projects:**
  * Data Visualization (`visualisation_work.txt`)
  * Dataset Analyses: Titanic, Tips, Placement, Churn, HR Attrition, and Supply Chain (`titanic_dataset_dividation_practice.txt`, `tips_dataset_analysis.txt`, `placement_dataset_analysis.txt`, `churn_data_analysis.txt`, `Attrition project.txt`, `supplychain_projectt.txt`)
